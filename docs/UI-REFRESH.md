## Added to the configuration

Original gradient, white and ink BoralancesOS marks; ten coordinated application icons; scalable and raster icon export; a branded Plymouth splash; first-run welcome; framed native installer with six stages, destination identity checks and user consent; region/appearance/effects installation choices; Control Center with actual backend controls; explicit shell-layer blur; pinned dock applications; a Mac-style application grid; consistent rounded chrome and traffic-light buttons.

The supplied `Liqui(1).html` informs the web material and switch mechanics directly. The browser preview uses the existing project's Snell-law factory and the reference track/thumb dimensions and spring constants. The native desktop's glass is provided by compositor blur, alpha and rim styling. Startup progress follows Plymouth callbacks; installation progress follows its child process. Neither native flow adds a fake wait or claims measured speed.

The desktop HTML is an interactive design artifact. Its menu and app cards are illustrative, and its installer/startup views are clearly labelled previews. The native installer is separate Python/Qt code invoked from live media; it has not performed an installation in this environment. A universal application-global menu is not implemented by drawing File/Edit/View labels in a prototype.

Source-only image pipelines remain in [BUILD.md](BUILD.md). Linux image builds, boot tests and performance acceptance remain pending.
